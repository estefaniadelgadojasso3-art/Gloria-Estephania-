Tarea 5

Dado el archivo FASTA, hacer un programa con las siguientes funciones.

1. Encabezados (1 punto)

Para todos los encabezados, imprimirlos en el formato:

"Organismo <el nombre del fasta>, contig <el contenido del encabezado, sin el ">">"

¿Qué hace?

Identifica las líneas del archivo que empiezan con el símbolo ">", quita ese símbolo e imprime el contenido utilizando la estructura solicitada.

2. Contenido GC (2 puntos)

Para cada línea de secuencia genómica, imprime su contenido GC en el formato:

"GC línea <número de línea>: <GC>"

¿Qué hace?

Calcula la proporción de bases de guanina y citosina en cada secuencia genómica. La cantidad de bases G y C se divide entre el número total de caracteres de esa misma línea.

3. Secuencia complementaria (2 puntos)

Para la primera secuencia de cada segmento, imprime su secuencia complementaria.

¿Qué hace?

Toma únicamente la primera línea de secuencia que aparece inmediatamente después de cada encabezado y muestra su complementariedad del ADN.

4. Buscar codón ATG (2 puntos)

Imprime el número de línea donde encuentre el codón ATG en el formato:

"ATG en línea <número de línea>"

¿Qué hace?

Detecta en qué líneas aparece el codón de inicio ATG.

5. GC total (2 puntos)

Calcula el contenido GC total del archivo y lo imprime al final en el formato:

"GC total del archivo: <GC>"

¿Qué hace?

Calcula la proporción global de G y C considerando todas las secuencias del archivo al finalizar la lectura.

import os

# Tabla para obtener la secuencia complementaria
TABLA_COMPLEMENTO = str.maketrans("ACGTacgt", "TGCAtgca")


def leer_fasta(ruta):
    with open(ruta, "r") as f:
        return [l.strip() for l in f.read().splitlines()]


def es_encabezado(linea):
    return linea.startswith(">")


def contar_gc(secuencia):
    s = secuencia.upper()
    return s.count("G") + s.count("C")


def imprimir_encabezado(nombre, linea):
    # 1. Encabezado
    print(f"Organismo {nombre}, contig {linea[1:]}")


def imprimir_gc_linea(num, secuencia):
    # 2. GC por línea
    gc = contar_gc(secuencia) / len(secuencia)
    print(f"GC línea {num}: {gc:.2f}")


def imprimir_complementaria(secuencia):
    # 3. Complementaria de la primera secuencia
    print(secuencia.upper().translate(TABLA_COMPLEMENTO))


def buscar_atg(num, secuencia):
    # 4. Línea donde aparece ATG
    if "ATG" in secuencia.upper():
        print(f"ATG en línea {num}")


def imprimir_gc_total(total_gc, total_bases):
    # 5. GC total del archivo
    if total_bases > 0:
        print(f"GC total del archivo: {total_gc / total_bases:.2f}")
    else:
        print("El archivo no contiene secuencias.")


def main():
    print("Directorio actual:", os.getcwd())
    ruta = input("Nombre del archivo FASTA: ")
    nombre = os.path.splitext(os.path.basename(ruta))[0]

    lineas = leer_fasta(ruta)

    total_gc = 0
    total_bases = 0
    es_primera = False

    for num, linea in enumerate(lineas, start=1):
        if linea == "":
            continue

        if es_encabezado(linea):
            imprimir_encabezado(nombre, linea)
            es_primera = True
            continue

        imprimir_gc_linea(num, linea)
        total_gc += contar_gc(linea)
        total_bases += len(linea)

        if es_primera:
            imprimir_complementaria(linea)
            es_primera = False

        buscar_atg(num, linea)

    imprimir_gc_total(total_gc, total_bases)


main()

6. Explicación del formato de archivo PDB

Nombre: Protein Data Bank (PDB).

Extensión: ".pdb".

¿Para qué se utiliza?

Se utiliza para almacenar información sobre la estructura tridimensional de moléculas biológicas, como proteínas y ácidos nucleicos. Contiene información sobre los átomos y sus coordenadas en el espacio.

Reglas del formato:

1. El archivo está organizado en líneas que contienen diferentes tipos de registros.
2. En el formato PDB tradicional, cada línea tiene 80 columnas.
3. Los primeros seis caracteres identifican el tipo de registro.
4. El registro "HEADER" contiene información general de la estructura.
5. El registro "ATOM" contiene información sobre los átomos de la molécula.
6. El registro "HETATM" contiene información sobre átomos de componentes no estándar.
7. El registro "END" indica el final del archivo.

Ejemplo:

HEADER    PROTEIN STRUCTURE
ATOM      1  N   MET A   1
ATOM      2  CA  MET A   1
ATOM      3  C   MET A   1
END

El ejemplo muestra algunos de los registros que pueden aparecer en un archivo PDB.
